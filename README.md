# SaaS Customer Health & Churn Prediction System

## Project Overview

This project builds an end-to-end machine learning system for predicting customer churn in a B2B SaaS business.

The goal is to identify customers who are at risk of cancelling their subscription, understand the main drivers of churn, and provide actionable insights that customer success teams can use for retention.

## Planned Workflow

- SQL data exploration
- Data cleaning and analysis with Python
- Exploratory data analysis
- Customer health feature engineering
- Churn prediction modelling
- Model evaluation
- Experiment tracking with MLflow
- Streamlit customer health dashboard
- FastAPI prediction endpoint
- Docker packaging
- GitHub Actions automation

## Tech Stack

Python, Pandas, NumPy, SQL, scikit-learn, XGBoost, MLflow, Streamlit, FastAPI, Docker, Git and GitHub.
